# SaaS Clínicas — Backend

API em NestJS. Visão geral do projeto no [CLAUDE.md](../CLAUDE.md) da raiz.

## Comandos

```bash
npm install
npm run start:dev   # servidor em modo desenvolvimento
npm run test        # testes unitários
npm run test:e2e    # testes end-to-end
npm run lint        # lint
```

Verificação de saúde: `GET /health`.
